Popamp apt repository

Packages of Popamp, its skins and its plug-ins for Debian and Ubuntu, x86_64 and ARM64. Add it once, and updates come with the rest of the system.

Add the repository

sudo mkdir -p /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/popamp.gpg https://apt.popamp.app/popamp.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/popamp.sources https://apt.popamp.app/popamp.sources
sudo apt update

Install

sudo apt install popamp        # the player
sudo apt install popamp-plus   # the player with plug-ins

Files

  • popamp.gpg: the signing key
  • popamp.sources: the sources entry, suite stable, component main
  • dists/stable/InRelease: the signed index

Built from the releases on GitHub by popamp/apt.
